# Többjegyűvel Szorzás Modul

## Maradékszámok (Carry Digits) Megjelenítése

A maradékszámok megjelenítése a "Maradékok megjelenítése" jelölőnégyzettel kapcsolható be.
Amikor be van kapcsolva, a szorzás közbeni átvitelek (maradékok) az adott számjegy jobb felső sarkában jelennek meg.

### Működése:
1. Minden szorzási lépésben kiszámítjuk a maradékokat
2. A maradékszámokat közvetlenül az adott cella jobb felső sarkában jelenítjük meg
3. Csak akkor láthatók, ha a funkció be van kapcsolva
4. A megjelenítés segít megérteni a szorzás helyiértékes lépéseit
